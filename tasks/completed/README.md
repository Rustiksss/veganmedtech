# Архив выполненных задач

Здесь хранятся только завершённые рабочие задачи `WORK-NNNN.md`. Спецификации функций остаются в `specs/`; их незавершённые пункты не переносятся сюда как выполненные.

Перед переносом агент обязан:

1. Убедиться, что текущая редакция имеет фактический аппрув разработчика.
2. Самостоятельно проверить каждый критерий и записать результат и свидетельства.
3. Обновить [состояние проекта](../../PROJECT_STATUS.md), проверить [технический долг](../../TECH_DEBT.md), записать результат проверки долга в задаче.
4. Установить `completed`, дату завершения и флаги `completion`; сохранить согласованный план и аппрув.
5. Перенести весь документ из корня, сохранив корректность ссылок, и восстановить [CURRENT_TASK.md](../../CURRENT_TASK.md) в `idle` со ссылкой на последнюю завершённую задачу.
6. Выполнить `python3 scripts/check_sdd.py` после переноса.

Задачи с неудачными/невыполненными критериями или статусом `blocked` остаются текущими. Не перезаписывайте архив и не используйте занятые ID; перед созданием следующей задачи найдите максимальный номер. При обнаружении ошибки в закрытой задаче оформите новую текущую задачу со ссылкой на предыдущую.

Подробный формат — в [процессе SDD](../../docs/workflow/sdd.md). Самопроверка обязательна; отдельный второй аппрув после неё процессом не требуется.
