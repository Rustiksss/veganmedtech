## Негативные проверки валидатора

На изолированных временных копиях поочерёдно внесены восемь ошибок. В каждом случае валидатор завершился с кодом `1`, сообщил ожидаемую причину и не вывел traceback:

1. Неизвестный ID требования в трассировке.
2. Повтор ID требования в реестре.
3. Битая локальная ссылка.
4. Изменение PDF без обновления хеша.
5. Статус теста `passed` без свидетельства.
6. Неверный тип значения статуса спецификации.
7. Производное требование без обоснования.
8. Критерий приёмки без трассировки.

Одноразовый прогон выполнялся через `tempfile` и `subprocess`; временные копии удалены. Эти восемь проверок и успешное заполнение шаблона дали результат **9/9**. Исходный PDF при этом не изменялся.
