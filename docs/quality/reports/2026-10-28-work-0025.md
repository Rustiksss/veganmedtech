# WORK-0025: демонстрационные назначения

Дата: 2026-10-28. Локальный результат; на удалённом сервере эта функция не публиковалась. Поручение и предварительный аппрув разработчика записаны в CURRENT_TASK.md, редакция 1; после закрытия сохраняются в архиве задачи.

Врач открывает «Мои пациенты → История пациента», выбирает препарат и необязательный комментарий, нажимает «Проверить назначение», затем «Подтвердить демоназначение». Запись сохраняется в PostgreSQL и видна пациенту в «Назначениях». До подтверждения записи нет. Повтор того же подтверждения возвращает ту же запись; врач может назначать только связанным пациентам. История сохраняет врача, название, комментарий, дату и версию каталога. Назначения явно демонстрационные; это не действующие рецепты, автоматического подбора/дозировок/схем/отмены и медицинского допуска нет.

Каталог `demo-drugs-2026-10-28-v1`: Авиандр, Парацетамол, Ибупрофен, Амоксициллин, Лоратадин, Цетиризин, Омепразол, Метформин, Амлодипин, Лозартан, Аторвастатин. Это произвольные названия по поручению пользователя, без утверждения о пригодности для данного пациента. [Официальный сайт Авиандра](https://aviandr.ru/) технически проверен 2026-10-28 только для названия; клинические утверждения не переносились. Дополнительная проверка написания: [перечень фармакопейных статей](https://pharmacopoeia.regmed.ru/upload/iblock/0ad/0g6ugqdpqtviuy2d9bszsgkxixqa7il1.pdf) и публичные сведения ГРЛС. Действующие инструкции и клинический алгоритм в этот срез не входят; CON-004 целиком не закрыт.
