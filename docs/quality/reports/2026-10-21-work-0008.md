# WORK-0008: сервер, аккаунты и Docker

Проверки выполнены 2026-10-20–21; завершение 2026-10-21. Согласованная редакция 1 и реальный аппрув — [WORK-0008](../../../tasks/completed/WORK-0008.md). Проверен локальный серверный срез на полностью вымышленных данных. Исторические отчёты WORK-0003–WORK-0007 не используются как доказательство серверного доступа.

## Результат и версия

Реализованы email-регистрация, обязательное подтверждение адреса, вход/выход, восстановление и смена пароля, серверные сессии; заявка врача и отдельный допуск, назначение/отзыв ведущего врача служебными командами. Самоотчёт пациента сохраняется в PostgreSQL и доступен только ему и допущенному ведущему врачу. Есть история с курсором, серверная валидация, идемпотентность и отдельный аудит. Врач видит запись из независимой браузерной сессии.

Код сервера: backend/config, accounts, care, reports, audit. Интерфейс разделён на frontend/templates и frontend/static/css,js; исходные опросники перенесены без изменения данных/ключей. В корне больше нет второго index.html или questionnaires.js. Существующие локальные функции сохранены, личное состояние очищается при выходе/смене аккаунта. Документация и действующие ссылки обновлены.

Среда: Linux x86_64, Docker Engine 29.1.3, Compose 5.6.0, Python контейнера 3.13.16, PostgreSQL 18.6, Firefox 157.0.1. Основные lock-версии: Django 5.2.18, DRF 3.18.3, allauth 65.20.0, Gunicorn 25.3.0, Psycopg 3.3.6, WhiteNoise 6.12.0, argon2-cffi 25.1.0; сборка uv 0.13.4. Версии и API сверены с первичными источниками при выборе зависимостей; решение и ссылки — [ADR-0002](../../architecture/decisions/0002-backend-stack.md). Внешние медицинские источники не изменялись.

Локальный образ `veganmedtech-backend:work0008`, ID `sha256:1b7de10c2d8e24bff5e44cc0dc440fc843fcb5d1589d614333ac139dae9b2970`. Контрольные суммы исходников/lock/контейнерных файлов/проверок — [manifest SHA-256](2026-10-21-work-0008-sha256.txt). Финальная сборка выполнялась после исправлений frontend; серверные исходники после 32 тестов не менялись. Дополнительные проверочные скрипты выполняются с хоста и не входят в runtime-образ.

## Ограничения и долг

Поставка локальная, только вымышленные данные. Внешний SMTP, домен/TLS, публикация и промышленное размещение не выполнялись. Техническая HTTPS-конфигурация не означает проверенного внешнего TLS-контура. Проверен Firefox; другие браузеры, нагрузка и производственные RPO/RTO не измерялись.

На сервере сохраняются аккаунты, ведущие связи и самоотчёты. Опросники, чаты, настроение, уведомления, календарные отметки остаются в памяти вкладки; их отправка врачу/доставка и постоянная история не заявляются. Клинический движок, назначения и алерты отсутствуют. Известные ограничения ключей опросников и вопросы Q-004/Q-008/Q-016/Q-017 сохранены, медицинский/правовой допуск не заявляется.
