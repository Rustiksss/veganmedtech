## Что изменено

Найден и локально исправлен TD-006 в backend/assistant/client.py. При полном Content-Length и Connection: close настоящий HTTPResponse закрывает file object после последнего read1. Прежний цикл снова устанавливал timeout закрытому сокету, получал EBADF и превращал готовый ответ в unavailable. Цикл теперь завершается по response.isclosed(); если тело оборвалось с ненулевым остатком Content-Length, возвращается incomplete, даже когда полученные байты случайно составляют валидный JSON. Срок 18 с, размер 65536, модель/тарифы работающего приложения и отсутствие повторов сохранены. Дополнительные транспортные заголовки использовались только в исследовательских запросах, в runtime не добавлены.

Изменены только этот цикл/проверка framing и содержательные серверные тесты. [Проверка минимальности патча](client-patch-rev9.json): обратное применение ровно этих двух изменений даёт точный SHA опубликованного клиента. Новые модели/SDK/зависимости/схемы БД/интерфейс не добавлены. Инструкция runtime остаётся опубликованной русской редакцией 4. Экспериментальные инструкции сохранены в отчёте, в поставку не входят. Ненужные подготовленные копии программ деплоя удалены.
