## Изменение редакции 6 — выбор быстрой недорогой модели

Последнее поручение разработчика: **«а может найти другую недорогую модель, которая будет быстро отвечать?»**. Продолжается незавершённая WORK-0020 с прежней целью — работающий опубликованный демоалертинг. Редакция 5 с увеличением ожидания не одобрена и заменена этой редакцией. Код, действующие 18/30/25 с и работающий сервер по её плану не менялись; новых генераций не было.

Read-only диагностика собственной истории Polza уточнила причину: три прежних контрольных запроса имеют статус completed и `generationTimeMs` 42 617 / 55 711 / 55 571; наш клиент уже прекратил ожидание на 18 с. Внешний сервис не был полностью неработоспособен, но текущий маршрут не укладывается в согласованный срок. Тексты ответов из истории не извлекались, успешный анализ приложением не подтверждён. Это основание сменить модель, сохранив ограниченное ожидание, а не вводить 90 секунд.

Проверены первичные API `GET /api/v1/models` и `GET /api/v1/models/{id}` 2026-10-26. В каталоге 409 моделей, 10 top_provider укладываются в 6/12 ₽. Для сравнения выбраны ровно два кандидата:

| Кандидат | Разрешённый ID | Текущая цена вход/выход, ₽ за миллион | Свойства доступного маршрута |
| --- | --- | --- | --- |
| Mistral Small 3 | `mistralai/mistral-small-24b-instruct-2501` | 5.72686 / 9.162976 | deepinfra/fp8; контекст 32768, заявлены JSON object/schema, без reasoning-параметра |
| Mistral NeMo | `mistralai/mistral-nemo` | JSON-маршруты от 2.0616696 / 3.436116 | dekallm/fp8/deepinfra/fp8/parasail/fp8; контекст >=128000, заявлены JSON object/schema, без reasoning-параметра |

Скорость этих маршрутов **не измерена**; статус каталога не считается доказательством. Разработчик Mistral Small описывает модель как подходящую для диалогов с низкой задержкой и JSON, но приёмка будет по собственному серверному замеру: [карточка разработчика](https://huggingface.co/mistralai/Mistral-Small-24B-Instruct-2501). Qwen3.5-9B дешевле (1.6132/4.8396), однако её Polza-маршрут заявляет только max_tokens без JSON/reasoning-toggle, а модель думает по умолчанию; её включение не входит в эту редакцию. [Карточка Qwen](https://huggingface.co/Qwen/Qwen3.5-9B). Подготовленные безопасные метаданные без ключей находятся в `/tmp/work0020-polza-{candidates,shortlist,own-diagnostic}.json`; после аппрува сохранить их в отчёте.

Изменение решения: на собственных четырёх случаях сравнить два кандидата, выбрать **одну фиксированную модель**, прошедшую строгую схему/смысловые случаи/русский ответ и скорость. Целевой критерий контрольного прогона: **каждый полный ответ <18 с, медиана <=10 с**; среди прошедших выбрать меньшую медиану, при равной — меньшую стоимость. Это измерение данного прогона, не производственная гарантия. При первом сбое отдельного кандидата остановить его серию, зафиксировать отказ и перейти ко второму; автоматических повторов нет. Если оба не проходят, не менять серверную модель и не публиковать неподтверждённое решение.

Клиент остаётся стандартным HTTPS, `TIMEOUT=18`, 512 выходных токенов, потолки 6/12 ₽, 6 новых попыток/минуту, 100/сутки, до 10 собственных завершённых пар и один вызов на ход. Для этих не-reasoning моделей не отправлять неподдерживаемый reasoning. В demo добавить документированные `response_format={"type":"json_object"}` и `provider.require_parameters=true`, чтобы дешёвый маршрут без JSON не получил запрос; строгая серверная проверка/цитата/политика остаются обязательными. В off прежний обычный текст. Для меньшего контекста Small 3 ограничить полный исходящий prompt 24000 UTF-8 байт (включая системную инструкцию/текущий текст), удаляя только самые старые целые пары из максимальных десяти; текущий текст/инструкцию не обрезать. Консервативный запас необходим 32768-token контексту и не требует токенизатора/зависимости. Проверить длинную историю/смену прежней модели и не менять историю в БД.

Разрешённый список конфигурации содержит только два кандидата и прежний `deepseek/deepseek-v4-flash` для совместимости/отката. После выбора серверное `POLZA_MODEL` атомарно меняется на один конкретный выбранный ID; ключ и все остальные значения сохраняются, права 0600, приватная копия/сверка обязательны. Новый локальный default и README соответствуют выбору. Пользователь API не выбирает модель, автоматического запасного LLM/повторного вызова в runtime нет. Gunicorn/ожидание pending/Compose stop timeout не повышаются. Новые зависимости, SDK, сервисы, очередь и streaming не добавляются.

Общий контрольный бюджет: **до 30 попыток всего, включая уже выполненные 17**; максимум 13 новых. До 8 — сравнительные случаи двух кандидатов, 2 — через опубликованный HTTPS, до 3 — только необходимые явные повторы после исправлений. Каждая реальная/диагностическая попытка в журнале, отказ не обнуляет бюджет. Генерации и внедрение только после аппрува этой редакции.
