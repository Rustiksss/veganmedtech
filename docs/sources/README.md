| Страница | Содержание | Перенос в требования |

Научная обоснованность отражена в CON-008/NFR-005, клиническая применимость — в сценариях и медицинской проверке, удобство — в NFR-004, обязательные условия — в CON, восемь задач — в FR-001–FR-008, апробация — в QA-001. Из технических метрик выделено требование FR-009, поскольку извлечение историй болезни не названо отдельным пунктом на странице 1, но оценивается на странице 3. Формат входных историй и способ обработки уточняются при соответствующей задаче; отдельный пользовательский интерфейс для этого PDF не предписывает.

Дополнительные идеи команды хранятся в [brainstorm.md](../product/brainstorm.md) с собственным происхождением. Они не меняют текст или условия исходного PDF.

[case-brief.txt](case-brief.txt) — извлечённый текст с явными границами страниц. Это удобная копия для поиска, не самостоятельный клинический источник. При спорном распознавании или форматировании приоритет имеет оригинал PDF.

## Воспроизводимость

```sh
python3 scripts/extract_source.py --check
python3 scripts/extract_source.py
```

Команды выполняются из корня проекта. Нужен `pdftotext` из Poppler; Python-зависимостей нет. Скрипт сначала сверяет хеш, затем извлекает текст. Различия вывода между версиями Poppler нужно проверить перед обновлением сохранённой копии. Новый PDF требует обновить источник и проанализировать изменения требований, а не просто заменить контрольную сумму.
