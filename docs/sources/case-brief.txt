=== Страница 1 ===

Кейс:


Цифровой ассистент врача для ведения
пациента с тревожной и депрессивной
симптоматикой

   Задача: Создать инструмент поддержки принятия врачебных решений для ведения
   пациентов с тревожно-депрессивной симптоматикой.




Задачи инструмента:
  1.    Предлагает стандартизированные методы для оценки состояния пациента.


 2.     Предоставляет рекомендации/справочную информацию по возможным вариантам
        терапии.


 3.     Осуществляет учёт и оценку индивидуальных рисков и нежелательных явлений.


 4.     Обеспечивает мониторинг динамики состояния пациента.


 5.     Предоставляет пациенту интерфейс для самоотчета и самостоятельного отслеживания
        динамики состояния.


 6.     Обеспечивает каналами коммуникации для сопровождения лечебного процесса.


 7.     Позволяет оценить приверженность пациента лечению и рекомендациям врача.


 8.     Выявляет ситуации, требующие направления пациента к психиатру (для врачей других
        специальностей). Предоставляет рекомендации по дальнейшей маршрутизации
        пациента, исходя из полученных данных (“обязательно” и “желательно”, в зависимости
        от тяжести состояния).

=== Страница 2 ===

Обязательные условия:

●   Решение поддерживает как минимум две роли: «Врач» и «Пациент» с раздельными функциями и
    правами доступа.


●   Связь “врач-пациент”. Данные пациента связаны с его ведущим лечащим врачом: сведения,
    которые вводит пациент, попадают в карточку этого пациента у врача без участия третьих лиц.


●   Решение не выполняет клинических действий самостоятельно: назначение, изменение и отмена
    терапии, направление к психиатру и изменение плана лечения происходят только после
    подтверждения врачом.


●   Решение демонстрируется на клинических сценариях, в которых рассматривается назначение
    препарата «Авиандр». Каждый сценарий включает профиль пациента, рекомендации по
    лечению и маршрутизацию пациента.


●   Должен быть реализован механизм «алертинга»: система самостоятельно определяет
    критическое состояние пациента по соответствующим признакам (перечень признаков определяет
    команда), экстренно оповещает врача, производит ряд действий (которые определяет команда).


●   Сигналы о направлении к психиатру и предупреждения о безопасности терапии визуально
    выделены среди прочей информации; категории «обязательно» и «желательно» различимы
    между собой.


●   Решение рекомендует только лекарственные препараты, зарегистрированные в Российской
    Федерации, в пределах зарегистрированных показаний, противопоказаний и режимов
    дозирования. Решение о применении вне инструкции может принять только врач.


●   Использование клинических рекомендаций, диагностических шкал итп. Клинические
    рекомендации — действующие, одобренные Минздравом России. Международные
    рекомендации допускаются для дополнения, с явным указанием источника. Сведения о
    лекарственных препаратах — по действующей инструкции по медицинскому применению (общей
    характеристике лекарственного препарата), опубликованной в Государственном реестре
    лекарственных средств. Психометрические инструменты — валидированные, с валидированной
    русскоязычной версией. Команда указывает источник валидации и соблюдает условия
    использования инструмента (авторские права, лицензия).


●   Соответствие требованиям законодательства РФ.


●   Соблюдение конфиденциальности
